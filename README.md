# VYÓRE Frontend

Tienda virtual oficial de VYÓRE para blusas y tops femeninos.

Flujo MVP:
- catálogo de modelos;
- detalle por modelo con variantes de color;
- colores agotados deshabilitados;
- carrito simple;
- envío del pedido por WhatsApp.

No hay checkout de pago integrado. La disponibilidad final y el pago se validan por atención directa.
